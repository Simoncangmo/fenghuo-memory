# 挑战声明
我们，智鼠微光舰队，成员是陈苍墨、王雯锦、袁士博，决心在微光黑客松期间，为抗战老兵基金会工作人员，解决 “**志愿者反馈的老兵战场细节信息的收集以及归类难**"的问题。
我们计划的解决方案是 “**抗战实录网页 + 志愿者信息收集小程序**”。

# 核心功能清单与产品需求文档（PRD）框架
这是一份专为《抗战老兵史料收集小程序》（前端收集）及配套《抗战实录Wiki网页》（后端公开展示）设计的核心功能清单与产品需求文档（PRD）框架。该方案围绕“志愿者现场易用”与“公众查阅严谨”两个核心目标设计。

## 小程序端核心功能清单（志愿者收集工具）
1. **登录与身份认证**（确保数据来源可追溯）
- 微信一键登录：志愿者通过微信快捷登录。
- 实名认证/组织绑定：首次使用需绑定所属志愿者团队或进行实名备案，规避虚假史料风险。
- 离线工作模式：支持在无网/弱网村落正常填写表单、录音、拍照，数据暂存本地草稿箱，联网后一键异步上传。
2. **老兵/线索基础档案**（核心表单）
- 基础信息卡片：姓名、生卒年月、籍贯、现居地、身体状况。
- 抗战履历卡片：入伍时间、所属部队番号、长官姓名、参加战役（支持多段履历添加）。
- 关系网关联：可添加“家属/后代”及“已知大战友/引路人”的联系方式与姓名，自动建立人物图谱纽带。
3. **语音转述模块**（口述历史音视频抢救）
- 内置录音机：支持长达数小时的高保真音频录制。
- 打点标记（Marker）：录音过程中，志愿者听到关键事件（如：聊到“常德会战”或“某个牺牲战友”），可点击“打点”按钮。
- 打点备注：点击打点后，可快速录入或简写关键词（如：12分30秒 - 战友牺牲），便于后期网页端精准切片。
- 智能降噪提取：内置基础音频格式优化，尽量过滤现场环境杂音。
4. **老照片与物证数字化模块**（防畸变收集）
- 智能证件扫描取景框：拍照时自动识别老照片、勋章、旧证件的边缘，自动进行透视矫正、去阴影、图像增强。
- 图文绑定组件：严禁批量盲传。每上传一张照片，必须强制填写：
◦ 照片年份/时期
◦ 画面主体人物/物品描述
◦ 物证目前所有人/存放地
- 音画同步（可选）：支持针对某张老照片单独录制一段老兵的“照片背后的故事”短音频。
5. **合规与法律授权**（法务闭环）
- 线上知情同意书：内置《抗战史料公开授权协议书》。
- 电子签名板：老兵或其直系亲属在手机屏幕上手写签名。
- 语音授权存证（双保险）：志愿者点击录制，由家属口头朗读“本人同意将上述资料用于公开Wiki展示”，与电子协议一并提交。


## 抗战实录Wiki网页端（公众展示与查阅平台）
1.**首页与时空可视化**
- 抗战老兵时空地图：基于GIS地图，展示老兵的“行军路线图”或“出生地/战役地分布图”。用户点击地图上的点，可跳转至对应老兵。
- 数字纪念馆群落：按战役（如台儿庄战役）、部队（如第29军）、地区（如湖南抗战）分类的聚合专题页。

2.**老兵个人百科主页**（Wiki核心）
- 人物生平编年史：以时间轴形式，清晰展现老兵从入伍、参战、复员到晚年的完整一生。
- 高清物证展厅：瀑布流展示老照片、勋章、家书。鼠标悬停或点击可查看志愿者在现场录入的“图文绑定背景说明”。
- 音视频互动切片：
◦ 用户可以直接在线播放口述录音。
◦ 网页端提供“段落锚点”，用户点击右侧文字（如“撤退过程”），音频自动跳转到对应的时间戳播放。
- 人物关系图谱：- 动态可视化图谱，展示该老兵与“战友A（已建档）”、“长官B（历史人物）”、“后代C（线索提供者）”的关联。

3.**公众互动与共创线索补充**（纠错机制）：公众（如其他老兵后代、历史爱好者）发现数据有误或有新资料时，可在网页端点击“补充史料/报错”，提交的信息将流转回小程序管理后台审核。

4.**数字祭奠/献花**：针对已故老兵，提供线上留言、献花、点烛功能，增强网页的社会公益效应。
